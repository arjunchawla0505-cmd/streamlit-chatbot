# AI Chatbot Assistant 🤖

An interactive, intelligent chatbot application built using Python, Streamlit, and Google's Gemini API. It provides real-time, conversational responses in a clean, modern chat interface.

## 🚀 Live Demo

You can try out the deployed application here: 
👉 **[Live Streamlit App](https://aichatbot0505.streamlit.app/)** 
---

## ✨ Features

- **Powered by Gemini:** Leverages Google's state-of-the-art Gemini API for smart, contextual, and accurate responses.
- **Streamlit Chat Interface:** Seamless, conversational UI utilizing Streamlit's native chat elements (`st.chat_message` and `st.chat_input`).
- **Session Memory:** Retains the conversation history during the active session so you can have a continuous dialogue.

---

## 🛠️ Tech Stack

- **Framework:** Streamlit
- **LLM Engine:** Google Gemini API (`google-generativeai`)
- **Language:** Python 3
